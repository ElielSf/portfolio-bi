## 📊 Projeto em destaque — Olist

O principal projeto apresentado no portfólio utiliza dados públicos do e-commerce brasileiro **Olist**.

O dashboard foi desenvolvido em Power BI e dividido em três áreas principais:

### Visão Geral

Visão executiva dos principais indicadores do negócio, incluindo:

- Receita
- Pedidos
- Clientes
- Ticket médio
- Receita por categoria
- Indicadores por estado

### Evolução Temporal

Análise da evolução dos resultados ao longo do tempo:

- Receita mensal
- Quantidade de pedidos
- Ticket médio
- Crescimento mensal
- Crescimento anual

### Análise Comercial e Pagamentos

Análise de fatores que contribuem para os resultados comerciais:

- Categorias de produtos
- Vendedores
- Formas de pagamento
- Parcelamento
- Relação entre receita e volume
